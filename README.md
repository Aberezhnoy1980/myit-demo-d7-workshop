# «Строка» — утренний разбор обращений (D7)

Самостоятельное демо студии: посадочная вымышленной мини-школы «Строка». Человек пробует метод сам на учебной неделе мастерской и при желании выбирает практикум с ведущим. Школа, ведущий, мастерская, клиенты и набор в группу вымышлены.

Модернизация 11–12 ноября 2026 заменила прежнюю версию «Таблицы для малого бизнеса» (практикум и пробный урок). История и обоснование — в `docs/2026-11-11-product-review-and-concept.md`, все тексты разбора — в `docs/2026-11-11-trainer-content-package.md`. Проверки и приёмка — в `docs/acceptance.md`.

## Для кого

- **Участник продукта:** мастер или владелец небольшой мастерской или студии, который сам отвечает клиентам в мессенджерах, по телефону и почте.
- **Покупатель разработки:** эксперт или небольшая школа без своей платформы. Это рабочая гипотеза, а не подтверждённый спрос.

## Маршруты

| Адрес | Что там |
|---|---|
| `/` | Хаб: ситуация, предложение, образец итогового листа, два входа |
| `/razbor/` | Пробный разбор: шесть обращений, 13 вопросов, итог, разбор ошибок, лист, CSV, печать |
| `/praktikum/` | Практикум с ведущим: формат, программа, набор без даты, демо-форма записи |

Совместимые адреса: `/workshop/` ведёт на `/praktikum/`, `/sample/` — на `/razbor/`, `/v2/`, `/v2/razbor/` и `/v2/praktikum/` — на основные маршруты. Это статические страницы перехода, которые SvelteKit генерирует при пререндере: `meta refresh` и скрипт перехода с относительным адресом. Переход работает и без JavaScript, но сервер не отдаёт код 308 — на статическом хосте его нет.

## Что умеет пробный разбор

- Шесть обращений: Анна, Сергей, Ольга, Дмитрий, Марина, звонок Анны. Всего 13 вопросов.
- Неверный ответ → пояснение → повторный выбор. Верный ответ → пояснение → изменение рабочей таблицы.
- Итог: 4 дела на сегодня, 1 напоминание на среду, 1 закрытая задача, таблица из шести задач, число верных первых ответов.
- Разбор ошибок отдельным экраном. Ошибкой считается неверный первый ответ на вопрос.
- Рабочий лист: план на день, таблица, краткие правила, необязательные поля «Мой регламент».
- Материалы: CSV итоговой таблицы и CSV-шаблон на свою неделю, оба формируются в браузере.
- Печать листа и отдельная печать разбора ошибок — окном печати браузера, ориентир A4; PDF — через «Сохранить как PDF» в том же окне.

## Чего здесь нет

- **Записи и отправки данных.** Демо-форма только проверяет поля на странице. Ничего не уходит в сеть и не сохраняется в хранилищах браузера, адресе или cookie. Подтверждение прямо говорит, что записи и брони не было.
- **Сохранения прогресса.** После перезагрузки разбор начинается заново, и введённый регламент пропадает. Роутер SvelteKit при перезагрузке пишет в `sessionStorage` служебную историю прокрутки и пустые снимки; ответов и данных формы там нет.
- **Замера времени.** «Около 6 минут» — оценка автора, на людях не измерялось.
- **Сервера, аналитики и внешних сервисов.**

## Окружение и команды

Нужен Node `>=22.17`. Проверено на Node `v22.23.4` и npm `10.9.9`. Пакеты зафиксированы в `package.json`.

```sh
npm test         # unit-тесты: движок разбора, CSV, демо-форма
npm run build    # статическая сборка в build/
npm run preview  # 127.0.0.1:4173
npm run measure  # файловая оценка веса трёх основных страниц
```

Если после новой сборки страница открывается без оформления или не работают кнопки, preview нужно перезапустить: он держит прежний список файлов.

Префикс для размещения в подкаталоге задаётся только на время сборки — пустой или вида `/demo/d7`:

```sh
BASE_PATH=/demo/d7 npm run build
```

Ссылки в сборке относительные. После сборки с префиксом верните корневую: `npm run build`.
