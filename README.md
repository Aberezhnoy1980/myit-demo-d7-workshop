
## Что делает кнопка регистрации

Форма вызывает `submitDemoRegistration` в режиме `mock`. Надпись при локальном ответе ровно: «Демонстрация: регистрация не отправлена». HTTP-режим выключен флагом `HTTP_MODE_ENABLED = false`. Сеть для заявки не вызывается.

Календарь, текст урока и CSV — обычные ссылки. Скачивание само ничего не отправляет.

## Сборка и префикс

`npm run build` пишет статику в `build/`. Ссылки относительные, со слэшем на конце: `./workshop/`, `../sample/`.

Префикс задаётся только на время сборки:

```sh
BASE_PATH=/demo/d7 npm run build
```

Пустое значение или префикс вида `/demo/d7` (начинается с `/`, без `/` в конце). Проверка 4 ноября 2026: при `BASE_PATH=/demo/d7` в HTML не осталось `href="/"`. Затем сборка без префикса восстановлена, в `build/` лежит корневой вариант. Префикс в браузере не открывался.

## Размещение и откат

Предложение, не выполненное действие: скопировать содержимое `build/` в каталог статического хоста, сохранив дерево папок. Откат — вернуть предыдущий каталог. Публикация, домен и сервер здесь не настраивались.

Контактов и адресов получателя нет: форма их не спрашивает, серверный приём не подключён.
