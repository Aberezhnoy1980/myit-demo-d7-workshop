## Дефекты и правки

- В SvelteKit 3 нет `$lib`. Импорты переведены на `#lib`.
- У Newsreader в используемом пакете нет кириллицы. Заголовки на Source Serif 4.
- Ключ идемпотентности нельзя было создавать при SSR: сервер и браузер расходились. Ключ создаётся в `onMount`, кнопка до этого выключена.
- На ширине около 900px таблица растягивала страницу. Две колонки включаются с 1100px, на первом экране у таблицы три колонки, полная таблица остаётся в уроке.
- `aria-invalid` снят с радиокнопок: предупреждение Svelte. Текст ошибки остался.
- После повторной сборки старый `vite preview` отдавал 404 на новый CSS. Превью перезапущено, стили применились.
