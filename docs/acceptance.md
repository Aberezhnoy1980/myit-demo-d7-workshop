# Приёмка

## Модернизация «Строка», 12 ноября 2026 — текущая версия

Разделы ниже, начиная с ревизии 5 ноября, относятся к прежней версии «Таблицы для малого бизнеса». Код, к которому относились их проверки, удалён 12 ноября.

### Приёмка владельца

- Этап хаба и практикума: приняты визуальное и продуктовое направление, предложение и продающая составляющая, путь от пробы к практикуму, понятность результата.
- Полный разбор: владелец прошёл все шаги; замечаний к прохождению нет, разбор принят.
- Мобильный смоук владельца: горизонтального переполнения нет.
- Выпадающие списки формы: смещение и серое системное оформление владелец наблюдал только в Chrome с открытыми DevTools в режиме устройства. В доступных исполнителю браузерах это не воспроизвелось; по решению владельца оставлено как есть.
- Приёмка владельца не считается проверкой печати, CSV, разных браузеров или доступности.

### Проверки исполнителя

Среда: headless Chrome через уже установленный Playwright из соседнего демо `d2-photo` (в D7 ничего не устанавливалось) и встроенный браузер Claude (Chromium). Node `v22.23.4`.

## Вес

`scripts/measure.mjs` складывает HTML, CSS, все `url()` шрифтов в CSS и файлы по ссылкам. Это верхняя граница: календарь, CSV и текст не грузятся, пока по ним не нажмут. Шрифты в CSS указаны парами latin и cyrillic; браузер на кириллической странице запрашивал оба набора виденных начертаний.

| Страница | HTML и связанные файлы | Старт без скачиваемых файлов | JS gzip |
|---|---:|---:|---:|
| `/` | 97 685 байт | 97 685 | 0 |
| `/workshop/` | 219 040, включая `.ics` 866 байт | 218 174 | 43 759 байт (сырой JS 111 427) |
| `/sample/` | 110 303, включая CSV 1 080 и текст 2 608 | 106 615 | 0 |

Лимит задания: до 1 МБ на старт страницы и до 150 КБ gzip JS. Запас есть. CSS сборки `0.CYFT9Y68.css` — 8 449 байт.

Настоящий масштаб браузера 200% не включал. 720px — приближение такого масштаба для окна 1440. Скриншоты: `docs/screenshots/`. Файл PNG шире CSS-окна: так снимает инструмент. Смысл кадра проверялся по тексту на экране и по числам выше.

Клавиатуру от начала до конца не проходил. В дереве доступности есть подписи полей, одна основная кнопка и ссылки. `aria-invalid` на радиокнопку не ставится: Svelte это запрещает, ошибка остаётся текстом и `role="alert"`.
