## Вес

`scripts/measure.mjs` складывает HTML, CSS, все `url()` шрифтов в CSS и файлы по ссылкам. Это верхняя граница: календарь, CSV и текст не грузятся, пока по ним не нажмут. Шрифты в CSS указаны парами latin и cyrillic; браузер на кириллической странице запрашивал оба набора виденных начертаний.

| Страница | HTML и связанные файлы | Старт без скачиваемых файлов | JS gzip |
|---|---:|---:|---:|
| `/` | 97 685 байт | 97 685 | 0 |
| `/workshop/` | 219 040, включая `.ics` 866 байт | 218 174 | 43 759 байт (сырой JS 111 427) |
| `/sample/` | 110 303, включая CSV 1 080 и текст 2 608 | 106 615 | 0 |

Лимит задания: до 1 МБ на старт страницы и до 150 КБ gzip JS. Запас есть. CSS сборки `0.CYFT9Y68.css` — 8 449 байт.
